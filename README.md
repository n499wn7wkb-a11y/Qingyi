# 轻译 Qingyi

轻译是一款 macOS 划词翻译工具。读英文网页或其他外语资料时，选中文字，按快捷键就能在原文附近看译文。想留着复习的内容，可以存进 Apple 备忘录。

**[下载轻译 2.4.8](https://github.com/n499wn7wkb-a11y/Qingyi/releases/tag/2.4.8)** · 需要 macOS 26 或更新版本

## 怎么用

1. 在发布页的 **Assets** 下载 `Qingyi-2.4.8.zip`，解压并打开轻译。按系统提示授予辅助功能权限。
2. 在正在阅读的应用里选中文字，按 **⌃⌥T**（Control + Option + T），就能在弹窗里看译文。快捷键可以在设置里更改。
3. 想稍后回看时，可将译文存入 Apple 备忘录。

Google 翻译无需 API Key。也可以在设置中配置 Gemini、OpenAI、DeepSeek 或兼容 OpenAI 的接口。选中的文字会发送给你选择的翻译服务。
